# Piedra, papel, tijeras.
aplicación en python del conocido juego piedra, papel y tijeras.

## Indice

1. Objetivo del proyecto.
2. Caracteristias 
3. Tecnologia y dependencias.
4. Estructura.

## 1. Objetivo del proyecto. 
Desarrollar aplicación en CLI que permita al usuario jugar contra IA. 
  

## 2. Caracteristias
- modularidad.
- convención PEP8.
- escalabilidad.
- Testing.
- gestion de dependencias. 
- separacion responsabilidades.

## 3. Tecnologia y dependencias.
- python.
- pip como gestor de dependencias.
- pytest para pruebas automatizadas.
- Ruff para formato y análisis
- mypy para comprobación de tipos.
- Git control de versiones.
- Github repositorio remoto.
